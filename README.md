## Getting Started

### Requirements

- [NodeJS](https://nodejs.org/en/download) `24+`
- [pnpm](https://pnpm.io/installation) `11+`

### Installation

1. Clone the repository.

    ```sh
    git clone https://github.com/novaotp/itsnova.sh
    ```

2. Install the dependencies.

    ```sh
    pnpm install
    ```

3. Run the dev server.

    ```sh
    pnpm run dev
    ```
