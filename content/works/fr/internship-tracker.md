# **Task Manager App**

_A simple, elegant app to keep your tasks organized._

## **Overview**

The Task Manager App is a lightweight web application designed to help users manage their daily tasks efficiently. Inspired by the need for a clean, no-frills task management tool, this project aims to provide a user-friendly solution for productivity enthusiasts.

## **Features**

-   Add, edit, and delete tasks
-   Mark tasks as completed
-   Responsive design for mobile and desktop

## **Tech Stack**

-   **Frontend**: SvelteKit, JSDoc
-   **Database**: Firebase
-   **Others**: Tailwind CSS, Vitest

## **Challenges and Learnings**

I struggled with implementing routing for dynamic task pages. This taught me to debug deeply and read documentation more thoroughly. Also, I gained confidence in using Tailwind for rapid UI design.
